# Async Mailbox

## Overview

Async Mailbox is an asynchronous Python utility for connecting to an IMAP email server. It allows for authenticating to a mailbox, searching for specific messages, processing emails for content, and extracting URLs. This tool is designed for applications that require monitoring email contents for specific text or URLs.

## Features

- Connect to IMAP servers with authentication support.
- Select and read emails from a specified mailbox.
- Filter emails based on the content (plain or HTML).
- Extract URLs from the email content.
- Optionally delete emails after processing.
- Logging of actions for monitoring and debugging.
